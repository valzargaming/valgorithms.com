This page receives the result of a Twitch authorization. You have arrived without one, which usually means you opened it directly.

If you were expecting a token, start the flow again from wherever you began it — or use the form below.

Authorized

Twitch returned an access token. It is shown only in this tab and has not been sent anywhere — it arrived in the URL fragment, which browsers never transmit to a server.

Expires in

Treat this like a password. It can act on the authorizing account for every scope listed above. An implicit-grant token cannot be refreshed — when it expires you will have to authorize again. If you need a token that renews itself, use response_type=code and exchange it somewhere that holds your client secret.

Authorized

Twitch returned an authorization code. It is single-use, expires within a few minutes, and still has to be exchanged for a token by something that holds the client secret.

Code
Scopes

Exchange it from a machine you control, never from a browser:

curl -X POST https://id.twitch.tv/oauth2/token \
  -d client_id=YOUR_CLIENT_ID \
  -d client_secret=YOUR_CLIENT_SECRET \
  -d code=THE_CODE_ABOVE \
  -d grant_type=authorization_code \
  -d redirect_uri=

The redirect_uri in that exchange must be byte-identical to the one used to start the flow, or Twitch rejects it — even though no further redirect happens.

Discarded

Nothing has been displayed or stored. If you did not just start an authorization yourself, someone may have sent you this link hoping you would complete one on their behalf — close the tab.

Detail

redirect_mismatch means the redirect_uri sent to the authorize endpoint is not one of the URLs registered on the application. It has to match exactly — scheme, host, port and path, with www. and a trailing slash both counting as a difference.
