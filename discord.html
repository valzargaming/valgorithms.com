        Setting an application up to install from here

        In the Developer Portal, for the application:

        1. Installation → Installation Contexts: Guild Install only. Untick User Install.
        2. Installation → Install Link: Custom URL, set to
          Do this first — Discord will not make a bot private while its install link is Discord’s own.
        3. Bot → Public Bot: off, so only you can add it.
        4. Bot → Requires OAuth2 Code Grant: off. This page cannot exchange a code, and with that on the bot would never join.
        5. OAuth2 → Redirects: add
          Exactly as shown — scheme, host and path all count, and www. is a different host.

        A new application is added to this page through the site build’s DISCORD_APPS_JSON; its client ID is public, but only the ones listed there can be installed from here.
