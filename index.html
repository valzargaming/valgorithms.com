The shelf

A sample of what’s maintained here. All MIT, all async PHP on ReactPHP, all with real users filing real issues.

Libraries

  • DiscordPHP

    The async PHP library for building Discord bots, on ReactPHP.

    https://github.com/discord-php/DiscordPHP

  • DiscordPHP-Http

    The standalone HTTP + rate-limit layer the library talks to Discord through.

    https://github.com/discord-php/DiscordPHP-Http

  • DiscordPHP-Voice

    Voice send/receive, Opus & DAVE end-to-end encryption for DiscordPHP.

    https://github.com/discord-php/DiscordPHP-Voice

  • DiscordPHP-NHA

    API library (and bot) for the "No Human Allowed" agent-sandbox world, with an LLM autoplayer.

    https://github.com/valzargaming/DiscordPHP-NHA

  • DiscordPHP-MTG

    A Magic: The Gathering API library and bot — card search and rules on top of DiscordPHP.

    https://github.com/valzargaming/DiscordPHP-MTG

  • TwitchPHP

    Async Twitch framework for PHP — Helix REST, EventSub over WebSocket, and IRC chat, built like DiscordPHP.

    https://github.com/Valgorithms/TwitchPHP

  • TwitchPHP-Http

    The standalone Helix transport for TwitchPHP — async queue, points rate-limiting, typed errors.

    https://github.com/Valgorithms/TwitchPHP-Http

  • DiscordPHP-EventLogger

    Drop-in audit logging for DiscordPHP bots — every gateway event, formatted.

    https://github.com/valzargaming/DiscordPHP-EventLogger

  • NFG

    Note Form Generator — a dependency-free HTML/JS tool that turns inline JSON schemas into tabbed forms and exports a standalone page.

    https://github.com/valzargaming/NFG

Bots

  • Civilizationbot

    Civ13’s official Discord bot — game-server management, player verification, moderation.

    https://github.com/valzargaming/Civilizationbot

  • DiscordPHP-Tutelar

    A Discord community-management bot — event logging, native onboarding, rotating presence, per-guild config — on a PSR-4 module architecture.

    https://github.com/discord-php/DiscordPHP-Tutelar
